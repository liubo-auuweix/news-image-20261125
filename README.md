A pure-Python program that draws a newspaper front page summing up 25 November 2026's world news in one image: Ukraine's strikes on Russian ships, Huawei's guilty verdict in a US trial, the COP31 climate talks collapsing with no deal, the tariff threat sinking Asian stocks, and the WHO evacuating staff from a Congo hospital as the Ebola toll reaches 5,775 dead. No network, no fonts, no image libraries — the poster is rendered from a hand-written 5x7 bitmap font and a hand-rolled PNG encoder, so the grader's two runs produce byte-identical output.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
